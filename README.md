# Portafolio Personal - Meily Milena Barreiro Gonzalez

## Descripción

Portafolio personal web desarrollado como parte de mi formación académica en **Ingeniería en Sistemas Inteligentes**.

El sitio presenta información personal, habilidades, proyectos académicos y una sección de contacto mediante un formulario visual.

El proyecto fue desarrollado utilizando **HTML5 y CSS3** y almacenado en un repositorio de **GitHub**.
